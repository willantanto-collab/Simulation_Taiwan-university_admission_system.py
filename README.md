# Simulation_Taiwan-university_admission_system.py
 为华侨生申请台湾的大学提供精准的加权计算与录取模拟

Taiwan_University_model 是关于class,def 的python。内容是为了稳固基础以及去在实战中理解大学系统中的一部分处理问题的逻辑。

algorithm.py 刚开始写的是一些系统防御的功能，class SecureDocument 与其类似的。其中还包含lessig Code is law 的一部分，scapy 网络层的1-7 层，格式写的是layer 4 - layer 1,然后是layer 5 - layer 7。

为不影响观看这些代码出现异常，避免不同文件和语言导致的这些故障或影响观看，所以也添加了能包容这些文件和语言（英文，中文） 的代码。还有scapy ,RFC 791,这种都是自学学会的。主要学习来源是从Wikishark scapy学的，以及自已的好奇心来搜索，了解到的一些内容。
